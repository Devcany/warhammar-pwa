🎯 WarhammAR Scanner

Diese Progressive Web App demonstriert einen KI-basierten Scanner für Warhammer 40K Miniaturen. Perfekt für Sammler und Spieler!

✨ Features:

  • 📱 Progressive Web App - Installierbar auf allen Geräten
  • 🤖 KI-Scanner Simulation mit realistischen Erkennungsraten
  • 📚 Erweiterte Warhammer 40K Datenbank
  • 📊 Sammlungs-Management
  • 🌙 Dark Theme Design
  • 📴 Offline-fähig

📱 Installation:

  1. Safari öffnen (nur Safari unterstützt PWA-Installation)
  2. "Teilen" Button tippen (📤)
  3. "Zum Home-Bildschirm" wählen
  4. App-Name bestätigen → "Hinzufügen"
  5. WarhammAR läuft wie eine native App! 🚀
